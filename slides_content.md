## Slide 4: Passo 1 - Baixar Projeto
**Título:** PASSO 1️⃣ - Baixar o Projeto (2 minutos)

**Instruções Numeradas:**
1. Abra o navegador
2. Acesse GitHub
3. Clique em "Code" (botão verde)
4. Clique em "Download ZIP"
5. Extraia em C:\Projetos\atos2

**Imagem:** Screenshot do GitHub com botão Download

**Ícone:** 📥 Download

---

## Slide 5: Passo 2 - Instalar Expo Go
**Título:** PASSO 2️⃣ - Instalar Expo Go (2 minutos)

**Instruções Numeradas:**
1. Abra Google Play Store
2. Procure por "Expo Go"
3. Clique em "Instalar"
4. Aguarde terminar

**Imagem:** Logo Expo Go + Google Play Store

**Ícone:** 📲 Celular

---

## Slide 6: Passo 3 - Abrir Terminal
**Título:** PASSO 3️⃣ - Abrir Terminal Windows (1 minuto)

**Instruções Numeradas:**
1. Pressione Windows + R
2. Digite: cmd
3. Pressione Enter

**Imagem:** Screenshot do terminal Windows

**Ícone:** ⌨️ Terminal

---

## Slide 7: Passo 4 - Iniciar App (Parte 1)
**Título:** PASSO 4️⃣ - Iniciar App (3 minutos)

**Comando 1:**
```
cd C:\Projetos\atos2\frontend
```
Pressione **Enter**

**Imagem:** Terminal com comando

**Nota:** Copie e cole o comando no terminal

---

## Slide 8: Passo 4 - Iniciar App (Parte 2)
**Título:** PASSO 4️⃣ - Continuar...

**Comando 2:**
```
npm install
```
Pressione **Enter** e aguarde (pode levar alguns minutos)

**Imagem:** Terminal com instalação em andamento

**Nota:** ⏳ Aguarde pacientemente!

---

## Slide 9: Passo 4 - Iniciar App (Parte 3)
**Título:** PASSO 4️⃣ - Último Comando

**Comando 3:**
```
npm start
```
Pressione **Enter**

**Imagem:** Terminal com npm start

**Nota:** 🎯 Agora você verá um QR Code!

---

## Slide 10: Passo 5 - Abrir no Celular (Parte 1)
**Título:** PASSO 5️⃣ - Abrir no Celular (2 minutos)

**Instruções Numeradas:**
1. No terminal, procure pelo QR Code
2. Abra o Expo Go no celular
3. Clique em "Scan QR Code"

**Imagem:** Exemplo de QR Code + Expo Go

**Ícone:** 📱 Celular

## Slide 11: Passo 5 - Abrir no Celular (Parte 2)

1. Aponte a câmera para o QR Code
2. Aguarde conectar (30-60 segundos)
3. App carrega no celular

**Imagem:** Celular escaneando QR Code
