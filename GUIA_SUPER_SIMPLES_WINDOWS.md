# 📱 Guia SUPER SIMPLES - Windows + Celular

## ✅ Você tem tudo que precisa!

- ✅ Windows
- ✅ Node.js instalado
- ✅ Um celular Android

---

## 🎯 Objetivo Final

Instalar o app Atos2 no seu celular Android e testar.

---

## 📋 5 Passos Simples

### PASSO 1: Baixar o Projeto (2 minutos)

1. Abra o navegador
2. Acesse: https://github.com/seu-usuario/atos2
3. Clique em **"Code"** (botão verde)
4. Clique em **"Download ZIP"**
5. Extraia a pasta em um local fácil (ex: C:\Projetos\atos2)

**Pronto! Você tem o projeto no seu computador.**

---

### PASSO 2: Instalar Expo Go no Celular (2 minutos)

1. Abra a **Google Play Store** no seu celular
2. Procure por: **"Expo Go"**
3. Clique em **"Instalar"**
4. Aguarde terminar

**Pronto! Seu celular está pronto para receber o app.**

---

### PASSO 3: Abrir o Terminal do Windows (1 minuto)

1. Pressione: **Windows + R**
2. Digite: **cmd**
3. Pressione: **Enter**

**Pronto! O terminal abriu.**

---

### PASSO 4: Iniciar o App (3 minutos)

No terminal, copie e cole estes comandos (um por um):

```
cd C:\Projetos\atos2\frontend
```

Pressione **Enter**

Depois:

```
npm install
```

Pressione **Enter** e aguarde (pode levar alguns minutos)

Depois:

```
npm start
```

Pressione **Enter**

**Pronto! O app está rodando no seu computador.**

---

### PASSO 5: Abrir no Celular (2 minutos)

1. No terminal, você verá um **QR Code** (quadrado com padrão)
2. Abra o **Expo Go** no seu celular
3. Clique em **"Scan QR Code"**
4. Aponte a câmera para o **QR Code** no terminal
5. Aguarde o app carregar (30-60 segundos)

**PRONTO! O app Atos2 está aberto no seu celular! 🎉**

## ⚠️ Possíveis Problemas e Soluções

### "Não consigo abrir o terminal"
**Solução:**
1. Clique com botão direito na pasta
2. Selecione "Abrir PowerShell aqui"
3. Pronto!

### "npm: comando não encontrado"
**Solução:**
1. Node.js não está instalado corretamente
2. Reinicie o computador
3. Tente novamente

### "Não consegue conectar ao QR Code"
**Solução:**
1. Certifique-se que celular e computador estão na mesma WiFi
2. Abra o Expo Go novamente
3. Tente escanear novamente

### "App não carrega no celular"
**Solução:**
1. Aguarde 1-2 minutos
2. Verifique a conexão de internet
3. Feche o Expo Go e abra novamente

### "Diz que a porta está em uso"
**Solução:**
1. Feche o terminal
2. Abra um novo terminal
3. Tente novamente
